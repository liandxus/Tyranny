# 欢迎使用 IndeXar

这是你的第一篇知识档案。

## 什么是 IndeXar？

IndeXar 是一个个人知识档案库。它的名字来自 **Index**（索引）和 **Archive**（归档）的组合。

## 如何使用？

你可以创建任意数量的笔记，并使用 Markdown 语法撰写内容。

在笔记中，你可以使用标准的 Markdown 链接语法连接到其他笔记，例如：
[关于完美主义的思考](./perfectionism.md)
