# 实现任务：底部面板（当前文件标签栏）

## 概述

在主窗口底部增加一个可折叠、可拖动调整高度的面板，显示当前选中文件的标签列表。文件树页和标签页都能看到这个面板（共享同一 Widget 实例）。双击标签跳转到标签页并定位到对应标签节点。

## 布局改造

原布局（三层）：

```
工具栏
Notebook（文件树页 / 标签页）
```

新布局（四层）：

```
工具栏
Notebook（文件树页 / 标签页）        ← 弹性撑满
可拖动分隔条                           ← 新增
底部面板（当前文件标签栏）              ← 新增，可折叠
```

## 需求细节

### 1. 底部面板本体（CurrentFileTagsBar）

- 类型：`ttk.Frame`，放在 Notebook 外部
- 顶部有一行标题栏，显示 `▶ 当前文件标签`（折叠时）或 `▼ 当前文件标签`（展开时）
- 展开时内容区域：显示当前打开文件的标签列表（compact Listbox 或 TagChip 行）
- 折叠时：标题栏保留，内容区域隐藏，高度只占标题栏一行
- 没有打开文件时：内容区域显示"未打开文件"占位文字

### 2. 可拖动分隔条

- 放在 Notebook 和底部面板之间
- 鼠标悬停变为上下拖拽光标 (⇅)
- 按住拖动调整底部面板高度
- 双击分隔条 = 切换折叠/展开
- **最小值保护**：不可拖动低于 60px（折叠状态除外）
- **不实现"拖动到最小自动关闭"**
- 高度记忆持久化，跟随项目现有的持久化方案（和主题/字号/sidebar_width 用同一套机制）

### 3. 标签溢出处理

- 标签水平排列不使用换行
- 显示不下时：**水平滚动条**，不换行

### 4. 数据流

- 监听全局事件（或通过选中文件回调）`file_selected` / `file_closed`
- 选中文件 → 提取该文件 tags 列表 → 刷新底部面板显示
- 关闭文件 / 无选中 → 显示"未打开文件"

### 5. 交互：双击标签

- **无论在哪个页面双击** → 自动切换到标签页 → 展开并定位到该标签对应的 Treeview 节点
- 文件树页双击标签也跳转到标签页（文件树页只管预览，标签页是管理界面）

### 6. 不要自动折叠

- 不做窗口缩小时自动收缩/折叠逻辑
- 窗口缩小到最小时底部面板保持当前状态不变（手动控制唯一入口）

## 注意事项

- 底部面板和两个页面共享同一个实例，不是各页面独立创建
- 滚动条只考虑水平方向
- 尽量复用已有的事件系统和持久化机制
- 设计简洁，不要过度设计
