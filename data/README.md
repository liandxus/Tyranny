# IndeXar - 个人知识档案库

## 项目简介

IndeXar 是一个基于 Python 的桌面端个人知识档案库应用，专注于**本地 Markdown 文件的阅览、搜索与知识网络构建**。

---

## 设计原则

- **数据自主**：所有数据以 Markdown 纯文本存储在本地，用户拥有绝对主权
- **以阅读和检索为核心**：不做编辑（编辑用 Typora/VS Code），只做"找"和"看"
- **轻量内敛**：零外部依赖（仅使用 Python 标准库 + 少量纯 Python 第三方库），启动快，打包小
- **模块化分工**：获取知识用 AI/搜索，编写笔记用编辑器，归档与索引用 IndeXar

---

## 技术栈

| 层级 | 技术 |
| :--- | :--- |
| 语言 | Python 3.11 |
| 界面 | Tkinter（Python 标准库） |
| 数据存储 | Markdown 文件 + YAML 元数据 |
| Markdown 渲染 | `markdown` 库 → HTML → 自研 `HTMLParser` → `tkinter.Text` tag 样式 |
| 元数据解析 | `python-frontmatter` |
| 搜索 | 遍历匹配（文件名优先 + 内容匹配，含片段摘要与跳转） |
| 图标 | `Pillow` 绘制，规避系统 emoji 渲染差异 |

## 功能需求

### MVP 核心功能

| 功能 | 描述 | 优先级 |
| :--- | :--- | :--- |
| **文件树** | 左侧面板列出 `data/` 下所有 `.md` 文件，点击加载内容 | P0 |
| **Markdown 阅览** | 将 Markdown 渲染为格式化内容展示（标题、列表、代码块等） | P0 |
| **全文搜索** | 输入关键词，在所有笔记内容中匹配，返回文件名列表 | P0 |
| **内部链接跳转** | 识别 `[[文件名]]` 和 `[文本](./文件.md)`，点击跳转到对应笔记 | P1 |
| **切换面板** | 左侧按钮栏切换"文件树"和"标签列表"视图 | P1 |

### 扩展功能

| 功能 | 描述 | 优先级 |
| :--- | :--- | :--- |
| **搜索结果高亮** | 在阅读区将搜索词以黄底黑字高亮 | P1 |
| **搜索结果片段** | 结果列表显示文件名 + 含关键词的上下文 | P1 |
| **YAML 元数据解析** | 识别文件头部的 `title`、`tags`、`redirect` | P1 |
| **标签聚合** | 点击标签列出所有含该标签的笔记 | P2 |
| **重定向** | 解析 `redirect` 字段，自动跳转并显示来源提示 | P2 |
| **反向链接** | 阅读区底部显示"被以下笔记引用" | P2 |
| **新建笔记** | 程序内一键创建含 YAML 模板的空 `.md` 文件 | P2 |
| **编辑元数据** | 侧边面板可视化修改 `title`、`tags`、`redirect` | P2 |

## 界面设计

### 整体布局

```
┌──────────────────────────────────────────────────────────┐
│  IndeXar                                        [_][□][×]│
├────────────┬─────────────────────────────────────────────┤
│  [按钮栏]   │  [搜索框]                                   │
│  ┌────────┐ ├─────────────────────────────────────────────┤
│  │ 文件    │ │                                             │
│  │ 标签    │ │         内容展示区                           │
│  └────────┘ │     （Markdown 渲染后的阅览视图）             │
│             │                                             │
│  文件树/    │                                             │
│  标签列表   │                                             │
│             │                                             │
│  · note1    │                                             │
│  · note2    │                                             │
│  · note3    │                                             │
│             │                                             │
└────────────┴─────────────────────────────────────────────┘
```

### 区域说明

| 区域 | 内容 | 交互 |
| :--- | :--- | :--- |
| **左侧按钮栏** | "文件"按钮、"标签"按钮（垂直排列） | 点击切换下方视图 |
| **左侧面板** | 文件树（默认）或标签列表 | 文件名点击 → 右侧加载内容；标签点击 → 筛选笔记 |
| **右侧搜索框** | 输入框 + 搜索按钮 | 输入关键词 → 回车或点搜索 → 左侧切换为搜索结果列表 |
| **右侧内容区** | Markdown 渲染后的阅览视图 | 内部链接可点击跳转 |

### 左侧面板切换逻辑

```
┌─────────────────────┐
│  [文件]  [标签]      │  ← 切换按钮，当前选中高亮
├─────────────────────┤
│                     │
│  当前选中视图内容    │  ← 文件树 或 标签列表 或 搜索结果
│                     │
└─────────────────────┘
```

- 默认显示"文件"视图
- 点击"标签" → 显示所有标签及其关联笔记数
- 进行搜索后 → 自动切换为搜索结果视图
- 搜索结果视图顶部显示"← 返回文件树"

### 搜索交互流程

```
用户输入关键词 → 按回车/点击搜索
        ↓
左侧切换为搜索结果视图
        ↓
显示匹配文件名 + 上下文片段
        ↓
点击结果项 → 右侧加载完整内容，搜索词高亮
```

## 项目结构

```
IndeXar/
├── main.py               # 程序入口，初始化窗口
├── gui.py                # 图形界面，组装所有组件（含搜索与交互逻辑）
├── file_handler.py       # 文件读写、标签与反向链接索引构建
├── markdown_renderer.py  # Markdown → HTML → tkinter.Text 渲染
├── theme_manager.py      # 亮/暗主题配色
├── icon_renderer.py      # 用 Pillow 绘制界面图标
├── editor_detect.py      # 外部编辑器检测（App Paths / 注册表 / 常见路径）
├── context_menu.py       # 自绘无边框右键菜单
├── test_layout.py        # 布局调试脚本
├── assets/               # 图标资源（SVG / PNG）
├── data/                 # 笔记存储目录
├── index.json            # 标签 + 反向链接索引缓存
├── settings.json         # 本地个人配置（不纳入版本控制）
└── requirements.txt      # Python 依赖
```

**模块协作**：
- `main.py` → 启动 `gui.py`
- `gui.py` → 调用 `file_handler.py` 获取文件列表与内容、读写 `index.json` 索引
- `gui.py` → 调用 `markdown_renderer.py` 渲染笔记正文
- `gui.py` → 调用 `editor_detect.py` 检测并调用外部编辑器
- 搜索逻辑内嵌于 `gui.py::_do_search()`：遍历匹配 → 文件名/内容分类 → 片段摘要 → 点击跳转

## 开发路径

1. **跑通"文件树 → 内容展示"**：点击左侧文件名 → 读取 `.md` → 渲染 → 显示在右侧
2. **实现内部链接跳转**：解析 `[[链接]]` 语法 → 点击跳转到对应笔记
3. **实现全文搜索**：搜索框 → 遍历匹配 → 结果列表 → 点击查看
4. **加入索引**：启动时预建内存字典 → 搜索 O(1)
5. **加入标签与重定向**：解析 YAML 元数据 → 标签聚合 → `redirect` 跳转
