# IndeXar - 个人知识档案库

## 项目简介

IndeXar 是一个基于 Python 的桌面端个人知识档案库应用，专注于**本地 Markdown 文件的阅览、搜索与知识网络构建**。

---

## 设计原则

- **数据自主**：所有数据以 Markdown 纯文本存储在本地，用户拥有绝对主权
- **以阅读和检索为核心**：不做编辑（编辑用 Typora/VS Code），只做"找"和"看"
- **轻量内敛**：零外部依赖（仅使用 Python 标准库 + 少量纯 Python 第三方库），启动快，打包小
- **模块化分工**：获取知识用 AI/搜索，编写笔记用编辑器，归档与索引用 IndeXar

---

## 技术栈

| 层级 | 技术 |
| :--- | :--- |
| 语言 | Python 3.11 |
| 界面 | Tkinter（Python 标准库） |
| 数据存储 | Markdown 文件 + YAML 元数据 |
| Markdown 渲染 | `markdown` 库（`extra` + `sane_lists`）→ HTML → 自研 `HTMLParser` → `tkinter.Text` tag 样式（表格用 `Treeview`，图片用 `Pillow` 缩放后内嵌） |
| 元数据解析 | `python-frontmatter` |
| 搜索 | 遍历匹配（文件名优先 + 内容匹配，含片段摘要与跳转） |
| 图标 | `Pillow` 绘制，规避系统 emoji 渲染差异 |

## 操作说明

> 本节汇总应用的全部实际操作方式，与"帮助"面板内容同源。

### 1. 界面区域

| 区域 | 内容 |
| :--- | :--- |
| **标题栏** | 菜单（文件 / 编辑 / 视图 / 帮助）、最小化 / 最大化 / 关闭 |
| **活动栏**（最左竖条） | 文件、标签、搜索、回收站四个图标，点击切换侧栏面板；再次点击当前图标可收起侧栏 |
| **侧栏** | 文件树 / 标签列表 / 回收站，与内容区之间的分隔条可拖拽调宽 |
| **内容区头部** | 前进后退箭头、文件名、关闭按钮、搜索框、搜索、编辑、主题切换 |
| **内容区** | Markdown 正文、底部反向链接、超出宽度时下方出现水平滚动条 |
| **状态栏** | 左侧显示操作提示与当前文件，右侧显示当前字号 |

### 2. 打开笔记

- 文件树中**单击**文件名
- 标签面板中**双击**笔记名
- 搜索结果中**单击**结果项
- 正文中**单击**内部链接（`[[笔记名]]` 或 `[文字](笔记名)`）
- 底部"被以下笔记引用"中**单击**来源笔记
- 打开后文件树会自动选中对应条目

### 3. 前进与后退

- **Alt + ←** 返回上一篇、**Alt + →** 再前进一篇，也可点击内容区左上角的 `←` `→`
- 适用范围：内部链接、反向链接、搜索结果、标签面板、文件树等**所有跳转**
- 箭头变灰表示该方向已没有可跳转的笔记
- 只有"切换到不同笔记"才计入历史，切换主题、调整字号、切换图片模式等刷新不会计入

### 4. 搜索

- **入口**：活动栏第三个图标（放大镜）进入搜索面板；或在内容区头部的快捷搜索框输入后回车（会自动切到搜索面板）
- 搜索面板顶部为输入框 + 清空按钮，下方是结果列表，底部为未来的高级搜索预留扩展区
- 匹配规则：**大小写不敏感的子串匹配**；只搜正文，不搜 YAML 元数据
- 结果分三组：
  1. **当前文件** —— 逐条列出每处匹配的上下文片段，**点击片段**会滚动到正文对应位置并高亮关键词
  2. **文件名匹配** —— 文件名含关键词的笔记
  3. **内容匹配** —— 仅正文含关键词的笔记（文件名已命中者不重复出现）
- 点击结果项打开笔记；清空输入框即清空结果（不自动切回文件树，点活动栏对应图标即可切换）
- 不支持：模糊匹配、布尔查询、正则表达式

### 5. 标签

- 顶部搜索框可按名称过滤标签
- **单击**标签展开 / 折叠其下的笔记列表，**双击**笔记名打开
- **多选标签求交集**：
  - `Ctrl + 点击` → 逐个加选或取消（适合不相邻的标签）
  - `Shift + 点击` → 选中两次点击之间的连续范围
  - 顶部显示「标签A ∩ 标签B → N 个文件」，双击列表项打开笔记
- **当前文件标签**（面板底部区块）：
  - `＋ 添加标签` → 弹窗输入新标签（输入中的逗号会转换为分隔）
  - `－ 删除所选` → 删除列表中选中的标签
  - **双击**列表中的标签 → 跳到"标签"面板并定位该标签
  - 点击区块标题可折叠 / 展开；上方的分隔条可拖拽调整区块高度

### 6. 回收站

- 活动栏第三个图标进入；删除的笔记与文件夹移入 `data/.trash/`
- **双击**条目或按 **Enter** 恢复；按 **Del** 彻底删除（不可恢复）
- 右键菜单提供恢复、彻底删除等操作，支持多选批量处理
- 右上角"时间 ↑ / ↓"按钮切换按删除时间排序的方向；"清空"按钮清空回收站

### 7. 图片

- 语法：`![说明文字](图片文件名.png)`，也可写 `data/` 内的相对路径
- 默认按**适应宽度**显示：比正文宽时等比缩小，比正文窄时保持原样（不放大、不拉伸）
- 视图菜单可切换为**原始尺寸**，超出部分用内容区下方的水平滚动条查看
- 鼠标移到图片上，状态栏显示它的说明文字（说明写在地址后面的引号里）
- 图片可以做成链接，从而支持点击跳转：
  - `[![图](a.png)](笔记名)` → 单击跳转到站内笔记
  - `[![图](a.png)](https://example.com)` → Ctrl + 单击用浏览器打开
- 图片缺失或写成网络地址时，会显示灰色占位文字（网络图片不会被下载）

### 8. 表格

- 语法与标准 Markdown 一致，渲染为原生表格控件
- **Ctrl + C**：有选中行时复制当前单元格内容，否则复制整行（制表符分隔）
- **右键**表格 → 复制该单元格内容
- 限制：单元格内不支持换行，不能像文本框那样拖选

### 9. 链接

- 站内：`[[笔记名]]`、`[[笔记名|显示文字]]`、`[显示文字](笔记名)`、`[显示文字](./目录/笔记.md)`
- 站外：`[显示文字](https://example.com)` 或 `<https://example.com>`，**Ctrl + 单击**用默认浏览器打开
- 直接书写的裸网址（如 `https://example.com`）不会被识别为链接

### 10. 快捷键

| 快捷键 | 作用 | 生效范围 |
| :--- | :--- | :--- |
| `Alt + ←` / `Alt + →` | 后退 / 前进 | 全局 |
| `Del` | 删除选中项（移入回收站） | 文件树获得焦点时 |
| `F2` | 重命名选中项 | 文件树获得焦点时 |
| `Del` | 彻底删除（不可恢复） | 回收站列表获得焦点时 |
| `Enter` | 恢复选中条目 | 回收站列表获得焦点时 |
| `Ctrl + C` | 复制当前单元格 / 整行 | 表格控件获得焦点时 |
| `Esc` | 关闭当前对话框 | 各类弹窗 |

## 笔记格式

### YAML 元数据

写在 `.md` 文件开头，用 `---` 包裹：

```markdown
---
title: 笔记标题
date: 2026-09-10
tags: [标签1, 标签2]
---
```

- `tags` 会被收集到左侧标签面板，用于聚合与交集筛选；在标签面板增删标签时，程序只改 `tags` 字段，不会重排 front matter 中其它字段与书写格式
- `title` 与 `date` 会被解析，但暂不参与界面展示

### Markdown 语法支持

| 语法 | 写法 | 状态 |
| :--- | :--- | :--- |
| 标题 | `#` ~ `######` | 支持（六级样式递进） |
| 粗体 | `**文字**` | 支持 |
| 斜体 | `*文字*` | 支持 |
| 删除线 | `~~文字~~` | 支持（另支持 `<del>` HTML 标签） |
| 行内代码 | `` `code` `` | 支持 |
| 代码块 | 三个反引号围栏 | 支持 |
| 引用 | `>` | 支持（连续多行合并为同一引用块） |
| 无序列表 | `-` | 支持（嵌套需缩进 4 空格） |
| 有序列表 | `1.` | 支持（自动编号） |
| 分隔线 | `---` | 支持 |
| 表格 | `\| a \| b \|` | 支持（渲染为原生表格控件） |
| 链接 | `[文字](url)` | 支持 |
| 图片 | `![说明](图片.png "悬浮文字")` | 支持 |
| 任务列表 | `- [ ]` | **不支持**（会显示为普通列表项） |
| 高亮 | `==文字==` | **不支持**（原样显示） |
| 其它 HTML 标签 | `<u>` 等 | **不支持**（标签被忽略，文字保留；`<del>` 除外） |
| 裸网址 | `https://example.com` | **不识别**（需写成链接语法） |
| 段落内换行 | 单行换行 | 保留换行（不合并为空格） |

## 项目结构

```
IndeXar/
├── main.py               # 程序入口，初始化窗口
├── gui.py                # 主窗口装配与配置读写
├── file_handler.py       # 文件读写、标签/反向链接索引、标签交集计算
├── search_engine.py      # 全文检索（遍历匹配，纯逻辑无界面依赖）
├── config.py             # 本地配置读写（settings.json 的读取与校验）
├── markdown_renderer.py  # Markdown → HTML → tkinter.Text 渲染
├── theme_manager.py      # 亮/暗主题配色
├── icon_renderer.py      # 用 Pillow 绘制界面图标
├── editor_detect.py      # 外部编辑器检测（App Paths / 注册表 / 常见路径）
├── context_menu.py       # 自绘无边框右键菜单
├── ui/                   # 界面层（按面板拆分）
│   ├── shell.py          # 活动栏、菜单、状态栏、侧栏显隐
│   ├── titlebar.py       # 标题栏与窗口管理
│   ├── file_tree.py      # 文件树面板
│   ├── tag_panel.py      # 标签面板
│   ├── trash_panel.py    # 回收站面板
│   ├── content_view.py   # 内容区渲染与交互
│   ├── search.py         # 搜索交互与结果渲染
│   ├── dialogs.py        # 对话框、设置面板、帮助面板
│   ├── theme.py          # 主题应用（配色刷新）
│   └── common.py         # 界面共用小工具
├── assets/               # 图标资源（SVG / PNG）
├── archive/              # 归档的旧资源与调试脚本
├── data/                 # 笔记存储目录（含 .trash/ 回收站）
├── index.json            # 标签 + 反向链接索引缓存
├── settings.json         # 本地个人配置（不纳入版本控制）
└── requirements.txt      # Python 依赖
```

**模块协作**：

- `main.py` → 启动 `gui.py`，`gui.py` 组合 `ui/` 下各面板
- `ui/` → 调用 `file_handler.py` 获取文件列表与内容、读写 `index.json` 索引
- `ui/content_view.py` → 调用 `markdown_renderer.py` 渲染笔记正文
- `ui/search.py` → 调用 `search_engine.py` 执行全文检索
- 分层原则：GUI 只做界面与交互，数据计算、文件读写、检索算法各自独立成模块

## 开发路径

1. **跑通"文件树 → 内容展示"**：点击左侧文件名 → 读取 `.md` → 渲染 → 显示在右侧
2. **实现内部链接跳转**：解析 `[[链接]]` 语法 → 点击跳转到对应笔记
3. **实现全文搜索**：搜索框 → 遍历匹配 → 结果列表 → 点击查看
4. **加入索引**：启动时预建内存字典 → 搜索 O(1)
5. **加入标签与重定向**：解析 YAML 元数据 → 标签聚合 → `redirect` 跳转（重定向尚未实现）
