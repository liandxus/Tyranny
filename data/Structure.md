## IndeXar 功能清单

### 第一层：MVP 核心功能（必须实现，跑通基本流程）

这些是项目的骨架。没有它们，IndeXar 就不成立。

| 功能 | 说明 | 涉及模块 |
| :--- | :--- | :--- |
| **文件树浏览** | 左侧面板显示 `data/` 文件夹内所有 `.md` 文件列表，点击文件名在右侧展示内容 | `gui.py`, `file_handler.py` |
| **Markdown 渲染阅览** | 将 `.md` 文件的原始文本转换为格式化的富文本展示（标题层级、列表、粗体等） | `gui.py`, `markdown` 库 |
| **内部超链接跳转** | 识别笔记中的 `[[文件名]]` 和 `[文本](./文件.md)` 格式链接，点击后跳转到对应笔记 | `gui.py`，链接解析函数 |
| **全文搜索** | 输入关键词，在所有笔记内容中匹配，返回包含该词的文件名列表 | `search_engine.py` 遍历匹配（GUI 只渲染结果） |
| **基础界面布局** | 经典的左侧文件树 + 右侧上（搜索框）/下（内容展示）布局，窗口标题为“IndeXar” | `gui.py`, `main.py` |

**这一层跑通后，你就有了一个可用的个人知识档案库。**

---

### 第二层：扩展功能（核心稳定后追加）

这些功能让系统更好用，但不阻塞基本流程。

| 功能 | 说明 | 实现要点 |
| :--- | :--- | :--- |
| **搜索结果高亮** | 在阅读区将搜索词以黄底黑字高亮显示 | `highlight_keyword()` 函数 |
| **搜索结果片段预览** | 搜索结果列表显示文件名 + 包含关键词的上下文片段 | `gui.py::_extract_text_snippets()` |
| **反向链接面板** | 在阅读区底部显示“被以下笔记引用”列表，点击可跳转 | `file_handler.build_backlink_index()` 写入 `index.json` |
| **YAML 元数据解析** | 识别文件头部的 `title`、`tags`、`redirect` 等元数据 | `python-frontmatter` 库 |
| **重定向** | 解析 `redirect` 字段，自动跳转到目标文件，顶部显示“（重定向自xxx）” | `load_note_with_redirect()` 函数 |
| **标签聚合浏览** | 点击标签后列出所有包含该标签的笔记 | 基于元数据中的 `tags` 字段遍历匹配 |
| **模糊搜索** | 输入“完美主意”也能找到“完美主义” | `fuzzywuzzy` 库 |

### 第三层：未来优化（论文展望，不必须实现）

这些是“让工具更顺手”的锦上添花，你可以在论文的“总结与展望”中提及。

| 功能 | 说明 |
| :--- | :--- |
| **非模态设置面板** | 侧边浮动面板，可视化编辑当前笔记的元数据（标签、重定向目标） |
| **启动时索引（缓存）** | 将索引存为 `indexar_cache.json`，下次启动直接加载，避免重复扫描 |
| **文件变化监听** | 使用 `watchdog` 库监听 `data/` 文件夹变化，自动增量更新索引 |
| **桌面打包** | 使用 PyInstaller 将程序打包为独立 `.exe` 文件 |
| **界面主题切换** | 读取 `config.yaml` 配置文件，支持浅色/深色模式切换 |
